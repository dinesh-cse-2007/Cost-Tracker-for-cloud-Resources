📌 About The Project

Cost Tracker for Cloud Resources is a web-based application designed to monitor and manage the costs of cloud resources.

The system helps users track cloud resource usage, estimated costs, spending trends, and resource details through a simple and user-friendly dashboard.

It helps organizations understand where their cloud money is being spent and identify opportunities to reduce unnecessary cloud costs.


---

🎯 Problem Statement

Cloud platforms provide many resources, but managing their costs can be difficult.

Common problems include:

❌ Unexpected cloud bills

❌ Difficulty tracking resource costs

❌ Unused cloud resources

❌ Lack of centralized cost information

❌ Difficult budget monitoring

❌ No simple cost visualization

The Cost Tracker for Cloud Resources provides a centralized dashboard to monitor cloud resources and their estimated costs.

🚀 Installation

1️⃣ Clone Repository

git clone https://github.com/your-username/Cost-Tracker-for-cloud-Resources.git

2️⃣ Open Project

cd Cost-Tracker-for-cloud-Resources

3️⃣ Install Dependencies

cd backend
npm install

4️⃣ Create Database

CREATE DATABASE cloud_cost_tracker;

Import:

database/cloud_cost_tracker.sql

5️⃣ Configure .env

PORT=5000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=cloud_cost_tracker

6️⃣ Start Backend

npm start
